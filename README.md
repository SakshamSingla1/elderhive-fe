# elderhive-fe

ElderHive frontend — React 18 + TypeScript + Vite.

See the root-level `README.md` and `IMPLEMENTATION_PLAN.md` one directory up
(`~/SakshamSingla/elderhive/`) for full project context — this is one of two
repos (the other being `elderhive-be`) that make up the ElderHive project.

## Local dev

```bash
npm install
npm run dev      # serves on http://localhost:5173
npm run test     # vitest
```

See `.env.example` for the backend API base URL.
